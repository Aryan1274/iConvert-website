# iConvert Official Product & Release Website

The modern, ultra-fast landing page and release portal for [iConvert](https://github.com).

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run locally in development
npm run dev

# Build optimized production bundle
npm run build
```

## 🌐 Deploy to Vercel or Netlify (Free)

1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "feat: initial landing website"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/iConvert-website.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) or [netlify.com](https://netlify.com)
3. Import the repository — Framework preset: **Vite**
4. Deploy! Your site will be live with free global CDN and HTTPS in seconds.
